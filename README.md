# CurvyConnectedDangoGoGui
HTML5 Curvy Connected Dango Go Gui

This is a stand-alone HTML file. download it and open it with a web browser to use it.

# Current Features
One can play a game of Go

Scoring mode

Game tree

Rectangular boards

SGF export/import (Note: unable to export SGF files with boards larger than 52x52)

Choice of single click and double click to move

Alternate game mode where capturing stones changes the color of the stone rather than removing the stone

GNU Go and Leela Zero terminal board positions can be imported
